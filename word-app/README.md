# 단어카드 - 영어 단어 암기 앱

플래시카드와 간격 반복 복습으로 영어 단어를 외우는 앱입니다. 같은 코드로 두 가지 형태로 쓸 수 있습니다.

| 형태 | 설치 방법 | 공부 알림 |
|---|---|---|
| 설치형 웹앱 (PWA) | 웹 주소를 열고 "홈 화면에 추가" | 안드로이드 Chrome에서만 동작하고 늦거나 안 올 수 있음. 앱 안 안내는 항상 표시 |
| 안드로이드 앱 | APK 설치 또는 플레이스토어 | 정한 시간에 정확히 울림 |

## 기능

- **단어장 고르기**: 처음 실행하면 필수 영단어(112), 비즈니스·무역(52), 의류·봉제 실무(51), 내 단어장 중에서 고릅니다. 홈의 "단어장 바꾸기"로 언제든 바꿀 수 있습니다.
- **매일 20개**: 고른 단어장에서 하루에 새 단어 20개가 플래시카드로 나옵니다. 설정에서 10~40개로 바꿀 수 있습니다.
- **간격 반복 복습**: 카드를 뒤집은 뒤 모름 / 애매 / 알아요를 고르면, 다음 복습일이 1일 → 2일 → 4일 → 7일 → 15일 → 30일 … 로 정해집니다.
- **출석체크와 점수**: 출석 +10점, 연속 출석 하루마다 +2점(최대 +20), 7일·30일 연속 보너스, 카드·퀴즈 정답과 하루 목표 달성에도 점수를 줍니다. 200점마다 레벨이 올라갑니다.
- **공부 안 한 날 알림**: 정한 시간(기본 오후 8시)까지 공부를 안 했으면 알림이 옵니다. 공부한 날은 울리지 않습니다. 며칠 쉬고 앱을 열면 홈에 안내가 표시됩니다.
- **퀴즈**: 4지선다로 뜻 고르기, 뜻을 보고 영어 철자 쓰기. 틀린 단어는 오늘 복습에 다시 들어갑니다.
- **발음 듣기**: 단어와 예문을 미국식 발음으로 읽어 줍니다.
- **내 단어 추가**: 한 개씩 입력하거나 엑셀에서 복사해 붙여 넣고 CSV 파일로 한꺼번에 넣을 수 있습니다.
- **백업**: 기록은 휴대폰 안에만 저장됩니다. 설정에서 백업 코드를 복사해 두면 새 휴대폰에서 불러올 수 있습니다.

## 파일 구성

```
word-app/
  index.html            화면과 디자인
  app.js                앱 동작 (학습, 점수, 알림, 퀴즈, 단어장)
  words.js              기본 단어장 (영어|뜻|예문 형식, 여기에 단어 추가)
  sw.js                 오프라인 실행, 웹 알림
  manifest.webmanifest  설치형 웹앱 정보
  privacy.html          개인정보처리방침 (플레이스토어 등록에 필요)
  icons/, assets/       앱 아이콘, 시작 화면 이미지
  capacitor.config.json 안드로이드 앱 설정 (앱 ID, 이름)
  scripts/              빌드 스크립트
```

기본 단어를 늘리려면 `words.js`의 해당 단어장 목록에 `영어|뜻|예문` 한 줄을 추가하면 됩니다.

## 1단계: 휴대폰에서 먼저 써 보기 (테스트용 APK)

`word-app/` 폴더가 바뀌어 GitHub에 올라가면 **Actions → 단어카드 안드로이드 빌드**가 자동으로 실행됩니다.

1. GitHub 저장소의 **Actions** 탭 → 가장 최근 "단어카드 안드로이드 빌드" 실행을 엽니다.
2. 아래쪽 **Artifacts**에서 `wordcard-test-apk`를 내려받아 압축을 풉니다.
3. `app-debug.apk`를 안드로이드 휴대폰으로 옮겨 설치합니다. (출처를 알 수 없는 앱 설치 허용 필요)

## 2단계: 플레이스토어에 올리기

### 준비물
- Google Play 개발자 계정 (등록비 미화 25달러 1회): https://play.google.com/console
- 앱 서명 키 (아래 명령으로 한 번만 만들고, **잃어버리지 않게 안전한 곳에 보관**)

### ① 앱 ID 확정
`capacitor.config.json`의 `"appId": "app.wordcard.daily"`는 임시 값입니다. 플레이스토어에 한 번 올리면 **바꿀 수 없으니** 첫 업로드 전에 원하는 값(예: `com.회사이름.wordcard`)으로 바꾸세요.

### ② 서명 키 만들기 (PC에 Java가 있을 때)
```bash
keytool -genkey -v -keystore upload.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
base64 -w0 upload.jks > upload.jks.b64     # macOS: base64 -i upload.jks -o upload.jks.b64
```

### ③ GitHub에 키 등록
저장소 **Settings → Secrets and variables → Actions → New repository secret**에서 4개를 넣습니다.

| 이름 | 값 |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | `upload.jks.b64` 파일 내용 |
| `ANDROID_KEYSTORE_PASSWORD` | 키 저장소 비밀번호 |
| `ANDROID_KEY_ALIAS` | `upload` |
| `ANDROID_KEY_PASSWORD` | 키 비밀번호 |

그다음 Actions에서 빌드를 다시 실행하면 `wordcard-playstore-aab`(플레이스토어 업로드용 파일)도 만들어집니다. 다시 올릴 때마다 버전 번호는 자동으로 올라갑니다.

### ④ Play Console에서 등록
1. **앱 만들기** → 이름 "단어카드", 기본 언어 한국어, 무료.
2. **앱 콘텐츠**
   - 개인정보처리방침 URL: 웹앱을 배포한 주소 뒤에 `/privacy.html` (3단계 참고)
   - 데이터 보안: "사용자 데이터를 수집하거나 공유하지 않음"
   - 광고: 없음 / 콘텐츠 등급 설문: 교육 앱 / 대상 연령 선택
3. **스토어 등록정보**: 짧은 설명, 자세한 설명, 아이콘(`assets/icon-only.png`를 512×512로), 휴대폰 스크린샷 2장 이상, 그래픽 이미지(1024×500).
4. **테스트 → 비공개 테스트**에 AAB를 올립니다.
   - 2023년 11월 이후 만든 **개인** 개발자 계정은 테스터 12명 이상이 14일 동안 비공개 테스트를 해야 정식 출시를 신청할 수 있습니다. **회사(조직) 계정**은 이 조건이 없습니다.
5. 검토를 통과하면 **프로덕션**으로 출시합니다.

## 3단계 (선택): 웹 주소로 배포하기

아이폰 사용자나 링크로 나눠 줄 때는 웹앱으로 배포합니다.

- **GitHub Pages**: 저장소 Settings → Pages → Source를 "GitHub Actions"로 바꾸고, 이 작업이 `main` 브랜치에 합쳐지면 **단어카드 웹앱 배포**가 실행됩니다. (비공개 저장소는 유료 요금제에서만 Pages를 쓸 수 있습니다.)
- **Netlify Drop** 같은 무료 호스팅: `node scripts/build-web.mjs`로 만든 `www/` 폴더를 끌어다 놓으면 됩니다.

주소를 휴대폰에서 연 뒤 Chrome 메뉴(⋮) → "앱 설치", 아이폰은 Safari 공유 버튼 → "홈 화면에 추가".

## PC에서 직접 빌드하기 (선택)

Node.js 22, JDK 21, Android Studio가 있으면:

```bash
cd word-app
npm install
VERSION_CODE=1 npm run android:prepare
npx cap open android     # Android Studio에서 실행 또는 Build → Generate Signed Bundle
```

앱 내용을 수정했다면 `sw.js`의 `CACHE` 버전 숫자를 올려야 설치형 웹앱 사용자에게 새 버전이 반영됩니다.
