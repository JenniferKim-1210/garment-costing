# 내 메일 회신 알림 (Outlook 매크로)

받은 메일이 **내가 보낸 메일에 대한 회신**이면:

1. **빨간색 범주 `내 메일 회신`** 을 붙여서 받은 편지함 목록에서 눈에 띄게 표시하고
2. **Windows 알림**(화면 오른쪽 아래)으로 보낸 사람과 제목을 띄워 줍니다.
   - 알림을 **클릭하면 그 메일이 바로 열립니다.**
   - 알림의 **[회신 목록 보기]** 버튼을 누르면 회신만 모인 목록이 열립니다.
3. 회신만 모아 보는 **`내 메일 회신` 폴더**(검색 폴더)를 자동으로 만들어 **즐겨찾기**에 추가합니다.

별도 프로그램 설치 없이 Outlook 안에서 돌아가는 VBA 매크로입니다.

> ⚠️ **클래식 Outlook(Windows 데스크톱 Outlook)** 에서만 동작합니다.
> "새 Outlook(New Outlook)" 이나 웹 Outlook 은 매크로를 지원하지 않습니다.
> 오른쪽 위에 "새 Outlook" 토글이 켜져 있다면 끄고 사용하세요.

---

## 파일 구성

| 파일 | 설명 |
|---|---|
| `ReplyAlert.bas` | 매크로 본문 (VBA 편집기에서 **가져오기** 할 파일, 한글 Windows 인코딩) |
| `ThisOutlookSession.txt` | `ThisOutlookSession` 에 붙여넣을 7줄짜리 코드 |

---

## 설치 (5분)

### 1. 매크로 허용
Outlook → **파일 > 옵션 > 보안 센터 > 보안 센터 설정 > 매크로 설정**
→ **"모든 매크로에 대해 알림"** 선택 → 확인 → Outlook 재시작

(회사 정책으로 막혀 있으면 IT 담당자에게 문의하세요. 아래 "서명" 항목 참고)

### 2. 모듈 가져오기
1. Outlook 에서 **Alt + F11** → VBA 편집기 열림
2. 메뉴 **파일 > 파일 가져오기** → `ReplyAlert.bas` 선택
3. 왼쪽 트리의 **모듈 > ReplyAlert** 가 생겼는지 확인

### 3. 자동 실행 연결
1. 왼쪽 트리 **Microsoft Outlook 개체 > ThisOutlookSession** 더블클릭
2. `ThisOutlookSession.txt` 내용을 그대로 붙여넣기
   ```vb
   Private Sub Application_Startup()
       ReplyAlert.OnStartup
   End Sub

   Private Sub Application_NewMailEx(ByVal EntryIDCollection As String)
       ReplyAlert.OnNewMail EntryIDCollection
   End Sub
   ```
3. **Ctrl + S** 로 저장 → VBA 편집기 닫기 → **Outlook 재시작**
4. 재시작할 때 매크로 사용 여부를 물으면 **"매크로 사용"** 클릭

### 4. 동작 확인
- **Alt + F8** → `TestToast` 실행 → 오른쪽 아래에 알림이 뜨면 OK
- **Alt + F8** → `ScanRecentInbox` 실행 → 최근 14일 받은 메일 중 회신을 찾아 표시하고 회신 목록을 엶
- 메일 하나를 선택하고 `TestToast` 실행 → 알림을 클릭했을 때 그 메일이 열리면 OK

## 사용법

설치 후에는 **아무것도 안 해도 됩니다.** 새 메일이 올 때마다 자동으로 검사합니다.
Outlook 을 켤 때도 최근 1일치를 다시 검사해서, 꺼져 있는 동안 온 회신도 표시합니다.

### 알림 클릭
| 클릭한 곳 | 동작 |
|---|---|
| 알림 본문 / **[메일 열기]** | 그 회신 메일을 바로 엶 |
| **[회신 목록 보기]** | `내 메일 회신` 목록 폴더를 엶 |
| Outlook 시작 시 "회신 N건" 요약 알림 | 회신 목록 폴더를 엶 |

메일을 다른 폴더로 옮긴 뒤 알림을 클릭하면 메일 대신 회신 목록이 열립니다.

### 회신 목록 (`내 메일 회신` 폴더)
- Outlook 을 재시작하면 왼쪽 **즐겨찾기** 맨 아래에 `내 메일 회신` 폴더가 자동으로 생깁니다. (폴더 목록 > 검색 폴더 아래에도 있음)
- 받은 편지함과 그 하위 폴더에서 **내 메일에 대한 회신만** 모여 보입니다. 메일을 하위 폴더로 옮겨도 목록에 남습니다.
- 목록 위쪽 **[읽지 않음]** 필터를 누르면 아직 안 읽은 회신만 볼 수 있습니다.
- 확인이 끝난 메일은 선택하고 `ClearReplyMark` 를 실행하거나 범주를 해제하면 목록에서 빠집니다.
- 즐겨찾기에서 지워도 다시 추가하지 않습니다. 다시 열고 싶으면 `ShowReplyList` 매크로를 실행하세요.

### 목록에서 더 눈에 띄게 (선택)
**보기 > 보기 설정 > 조건부 서식 > 추가**
→ 이름 `내 메일 회신` → **글꼴**: 굵게 / 빨간색
→ **조건 > 고급 옵션(또는 기타 선택 항목) > 범주** → `내 메일 회신` 체크

### 수동 매크로 (Alt + F8)

| 매크로 | 기능 |
|---|---|
| `ShowReplyList` | 회신 목록 폴더 열기 |
| `ScanRecentInbox` | 최근 14일 받은 메일을 다시 검사해서 표시하고 회신 목록 열기 |
| `TestSelectedMail` | 선택한 메일이 왜 회신으로 판단됐는지/안 됐는지 진단 |
| `TestToast` | Windows 알림 테스트 (메일을 선택하고 실행하면 클릭 시 그 메일이 열림) |
| `ClearReplyMark` | 선택한 메일에서 `내 메일 회신` 표시 제거 |

자주 쓰는 매크로는 **파일 > 옵션 > 리본 사용자 지정** 에서 버튼으로 추가할 수 있습니다.

## 설정 바꾸기

`ReplyAlert` 모듈 맨 위 **설정** 부분의 값을 바꾸고 저장하면 됩니다.

| 설정 | 기본값 | 설명 |
|---|---|---|
| `CATEGORY_NAME` | `내 메일 회신` | 표시용 범주 이름 |
| `LIST_FOLDER_NAME` | `내 메일 회신` | 회신 목록 검색 폴더 이름 |
| `CREATE_REPLY_LIST` | `True` | 회신 목록 폴더 자동 생성 + 즐겨찾기 추가 |
| `CLICK_TO_OPEN` | `True` | 알림 클릭 시 메일 열기 |
| `SHOW_TOAST` | `True` | Windows 알림 표시 |
| `SHOW_POPUP` | `False` | 메시지 박스로 알림 (확인을 눌러야 닫힘) |
| `SET_FLAG` | `False` | 플래그를 달아 할 일 목록에도 표시 |
| `SET_HIGH_IMPORTANCE` | `False` | 중요도를 "높음" 으로 변경 |
| `MATCH_WHOLE_THREAD` | `False` | `True` 면 내 메일이 포함된 스레드의 모든 답장 표시 (예: 거래처 회신에 동료가 전체회신한 경우도 포함) |
| `SKIP_AUTO_REPLIES` | `True` | 부재중 자동회신 제외 |
| `SCAN_DAYS` | `14` | `ScanRecentInbox` 검사 기간 |
| `STARTUP_SCAN_DAYS` | `1` | Outlook 시작 시 검사 기간 (0 = 끔) |
| `EXTRA_MY_ADDRESSES` | `""` | 내 별칭 주소 (예: `"sales@company.com;me@company.com"`) |

## 어떻게 판단하나요?

메일에 답장을 하면, 답장 메일 안에 **"어떤 메일에 대한 답장인지"(In-Reply-To)** 정보가 들어갑니다.

1. 받은 메일의 In-Reply-To 값을 **보낸 편지함**의 메일 ID 와 비교 → 일치하면 회신
2. 보낸 편지함에 없으면(보낸 메일을 다른 폴더로 옮긴 경우 등) **같은 대화(스레드)** 에서 그 메일을 찾아 내가 보낸 것인지 확인
3. 이 정보가 없는 메일은 같은 대화에 **내가 먼저 보낸 메일**이 있는지로 판단

제목에 "RE:" 가 붙었는지로 판단하지 않기 때문에, 제목을 바꿔서 답장해도 잡히고, 남의 메일에 대한 RE: 메일은 표시되지 않습니다.

## 문제 해결

**알림이 안 떠요**
- `TestToast` 를 실행해 보세요. 안 뜨면 Windows **설정 > 시스템 > 알림** 에서 알림이 켜져 있는지, "방해 금지 / 집중 모드" 가 꺼져 있는지 확인하세요.
- 회사 정책으로 PowerShell 이 막혀 있으면 Windows 알림이 동작하지 않습니다. 이 경우 `SHOW_POPUP = True` 로 바꾸면 메시지 박스로 알려 줍니다. (빨간색 범주 표시는 PowerShell 과 상관없이 동작합니다.)

**알림을 클릭해도 메일이 안 열려요**
- 메일을 선택하고 `TestToast` 로 다시 확인해 보세요.
- 클릭 처리는 `%APPDATA%\ReplyAlert\open.vbs` 스크립트가 합니다(Outlook 시작 시 자동 생성). 회사 정책으로 **Windows Script Host(wscript)** 가 막혀 있으면 열리지 않습니다. 이 경우에도 빨간 표시와 회신 목록은 정상 동작합니다.
- 메일이 열렸는데 화면 뒤에 숨어 있으면 작업 표시줄의 Outlook 을 눌러 주세요. (Windows 가 다른 창이 앞으로 나오는 것을 막는 경우가 있습니다)
- 처음 클릭할 때 "이 앱을 여시겠습니까?" 같은 확인 창이 뜨면 허용해 주세요.

**회신 목록 폴더가 안 보여요**
- Outlook 을 한 번 재시작하거나 `ShowReplyList` 를 실행하세요.
- **폴더 목록 > 검색 폴더** 아래에 `내 메일 회신` 이 있으면 끌어서 즐겨찾기에 놓으면 됩니다.

**회신인데 표시가 안 돼요**
- 해당 메일을 선택하고 `TestSelectedMail` 을 실행하면 판단 근거가 나옵니다.
  - "내가 보낸 메일인가: 예" 로 나오면 → 내 주소 판별 문제. `EXTRA_MY_ADDRESSES` 확인
  - "In-Reply-To: (없음)" 이고 회신 아님 → 상대방 메일 프로그램이 답장 정보를 안 넣은 경우입니다.
- 서버 규칙으로 받은 편지함이 아닌 다른 폴더로 바로 들어가는 메일은 자동 검사가 안 될 수 있습니다.

**매크로가 실행이 안 돼요 / 재시작하면 안 돼요**
- 매크로 설정이 "모든 매크로 사용 안 함" 이면 동작하지 않습니다.
- 매번 "매크로 사용" 을 누르기 귀찮다면 자체 서명을 하세요:
  1. 시작 메뉴에서 **"VBA 프로젝트용 디지털 인증서"** (SelfCert.exe) 실행 → 이름 입력해 인증서 생성
  2. VBA 편집기 **도구 > 디지털 서명 > 선택** → 만든 인증서 선택 → 저장 후 재시작
  3. 처음 뜨는 경고에서 **"이 게시자의 모든 문서 신뢰"** 클릭

**한글이 깨져 보여요 (VBA 편집기에서)**
- `ReplyAlert.bas` 는 한글 Windows 인코딩(CP949)으로 저장되어 있습니다. Windows 의 "유니코드를 지원하지 않는 프로그램용 언어" 가 한국어가 아니면 깨질 수 있습니다. 동작에는 영향이 없지만 범주 이름 등이 깨질 수 있으니, 이 경우 `CATEGORY_NAME` 을 원하는 이름으로 직접 바꿔 주세요.

## 제거
1. VBA 편집기에서 `ReplyAlert` 모듈 우클릭 > **제거**, `ThisOutlookSession` 에 붙여넣은 코드 삭제 → 저장 → 재시작
2. 범주 `내 메일 회신` 은 **홈 > 분류 > 모든 범주** 에서 삭제
3. 검색 폴더 `내 메일 회신` 은 우클릭 > **폴더 삭제** (메일은 지워지지 않습니다)
4. 클릭 처리기: `%APPDATA%\ReplyAlert` 폴더 삭제, 레지스트리 `HKEY_CURRENT_USER\Software\Classes\replyalert` 키 삭제
