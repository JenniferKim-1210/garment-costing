# 메일 할 일 알리미 (Outlook 매크로)

메일이 너무 많아서 놓치는 것을 막기 위한 Outlook 매크로입니다.
메일을 4가지 **목록**으로 자동 분류하고, 정해진 시각에 **리마인드 알림**을 띄워 줍니다.

| 목록 (즐겨찾기에 자동 추가) | 색 | 무엇이 들어가나 | 알림 |
|---|---|---|---|
| **내 메일 회신** | 빨강 | 내가 보낸 메일에 **회신이 온** 메일 | 도착 즉시 |
| **내 앞으로 온 메일** | 보라 | 본문이 **"Hi Jennifer", "김나현 차장님"** 처럼 내 이름을 부르며 시작하는 메일 | (선택) |
| **내 답장 필요** | 파랑 | 나한테 왔는데 **아직 회신 안 했거나 안 읽은** 메일 | 매일 9시, 14시 |
| **답장 대기** | 주황 | 내가 보냈는데 **3일째 답이 없는** 메일 | 하루 한 번 |

- 알림을 **클릭하면 그 메일이나 목록이 바로 열립니다.**
- 회신·전달하면 `내 답장 필요` 에서, 상대가 답하면 `답장 대기` 에서 **자동으로 빠집니다.**
- 더 이상 회신하지 않을 메일은 **`MarkDone`(완료 처리)** 하면 모든 목록에서 빠지고 다시 들어오지 않습니다.

별도 프로그램 설치 없이 Outlook 안에서 돌아가는 VBA 매크로입니다.

> ⚠️ **클래식 Outlook(Windows 데스크톱 Outlook)** 에서만 동작합니다.
> "새 Outlook(New Outlook)" 이나 웹 Outlook 은 매크로를 지원하지 않습니다.
> 오른쪽 위에 "새 Outlook" 토글이 켜져 있다면 끄고 사용하세요.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `ReplyAlert.bas` | 매크로 본문 (VBA 편집기에서 **가져오기** 할 파일, 한글 Windows 인코딩) |
| `ThisOutlookSession.txt` | `ThisOutlookSession` 에 붙여넣을 코드 |

## 설치 (5분)

### 1. 매크로 허용
Outlook → **파일 > 옵션 > 보안 센터 > 보안 센터 설정 > 매크로 설정**
→ **"모든 매크로에 대해 알림"** 선택 → 확인 → Outlook 재시작

(회사 정책으로 막혀 있으면 IT 담당자에게 문의하세요. 아래 "서명" 항목 참고)

### 2. 모듈 가져오기
1. Outlook 에서 **Alt + F11** → VBA 편집기 열림
2. 예전 버전이 있으면 왼쪽 **모듈 > ReplyAlert** 우클릭 → **제거** (내보내기는 "아니요")
3. 메뉴 **파일 > 파일 가져오기** → `ReplyAlert.bas` 선택

### 3. 자동 실행 연결
1. 왼쪽 트리 **Microsoft Outlook 개체 > ThisOutlookSession** 더블클릭
2. 안에 있던 내용을 **모두 지우고** `ThisOutlookSession.txt` 내용을 붙여넣기
   ```vb
   Private WithEvents SentItems As Outlook.Items

   Private Sub Application_Startup()
       Set SentItems = Application.Session.GetDefaultFolder(olFolderSentMail).Items
       ReplyAlert.OnStartup
   End Sub

   Private Sub Application_NewMailEx(ByVal EntryIDCollection As String)
       ReplyAlert.OnNewMail EntryIDCollection
   End Sub

   Private Sub SentItems_ItemAdd(ByVal Item As Object)
       ReplyAlert.OnItemSent Item
   End Sub
   ```
3. **Ctrl + S** 로 저장 → VBA 편집기 닫기 → **Outlook 재시작**
4. 재시작할 때 매크로 사용 여부를 물으면 **"매크로 사용"** 클릭

### 4. 완료 처리 버튼 만들기 (추천)
`MarkDone` 을 자주 쓰게 되니 버튼으로 만들어 두세요.
1. **파일 > 옵션 > 리본 사용자 지정** (또는 **빠른 실행 도구 모음**)
2. 왼쪽 "명령 선택" 에서 **매크로** 선택 → `Project1.MarkDone` 을 오른쪽으로 추가
3. **이름 바꾸기** 로 "완료" 등 알기 쉬운 이름과 체크 아이콘 선택

빠른 실행 도구 모음에 넣으면 **Alt + 숫자** 단축키로도 쓸 수 있습니다.

### 5. 동작 확인
- 메일 하나를 선택하고 **Alt + F8** → `TestToast` 실행 → 알림을 클릭했을 때 그 메일이 열리면 OK
- **Alt + F8** → `CheckMyTodo` → 내가 회신 안 한 메일을 찾아 `내 답장 필요` 목록을 엶
- **Alt + F8** → `CheckNoReply` → 답이 없는 보낸 메일을 찾아 `답장 대기` 목록을 엶
- **Alt + F8** → `ScanRecentInbox` → 최근 14일 받은 메일 중 내 메일 회신과 내 앞으로 온 메일을 찾아 표시

## 목록별 설명

### 🔴 내 메일 회신
- 받은 메일이 **내가 보낸 메일에 대한 회신**이면 빨간색으로 표시하고 바로 알림을 띄웁니다.
- 알림 본문 / **[메일 열기]** → 그 메일 열기, **[회신 목록 보기]** → 목록 열기
- 그 회신에 내가 다시 답하면 목록에서 빠집니다. 답할 필요가 없으면 `MarkDone`.

### 🟣 내 앞으로 온 메일
받는 사람에 내가 있는지가 아니라, **본문이 나를 부르며 시작하는지**를 봅니다. 참조(CC)로 받았어도 나를 불렀으면 표시됩니다.

본문 앞 5줄 안에서 (외부메일 경고 문구 등이 앞에 있어도 됨) 이런 줄을 찾습니다.

| 표시됨 ✅ | 표시 안 됨 ❌ |
|---|---|
| Hi Jennifer, / Dear Jennifer, / Hello Jennifer! | Hi all, ↵ Jennifer will send the file… (나를 3인칭으로 언급) |
| Good morning Jennifer, / Attn: Jennifer / @Jennifer | Hi Tom, ↵ Please cc Jennifer. |
| Hi Tom and Jennifer, | Today Jennifer said… |
| Jennifer, please confirm… | 팀원 여러분, ↵ 김나현 차장님이 보내주신 자료… |
| 김나현 차장님, / 김 나현 차장님 안녕하세요 | 박 과장님, ↵ 김나현 차장님께서 요청하신 건… |
| 안녕하세요 김나현 차장님, / 수신: 김나현 차장님 / 김나현 차장님께, | 김나현 님이 문서를 공유했습니다 |

- 이름은 설정 `ATTENTION_NAMES` 에 있습니다. 기본값: `"Jennifer;김나현;김 나현"`
  - 다른 호칭으로도 자주 받으면 추가하세요. 예: `"Jennifer;Jenny;Ms. Kim;김나현;김 나현;김 차장"`
- 이 메일들은 **참조(CC)나 단체 메일이어도 `내 답장 필요` 에 들어갑니다.** (나를 불렀으니 답해야 할 가능성이 높음)
- 뉴스레터처럼 자동 발송된 메일은 "Dear Jennifer" 로 시작해도 제외합니다.
- 내가 회신하면 목록에서 빠집니다. 도착할 때 알림도 받으려면 `ATTENTION_TOAST = True`

### 🔵 내 답장 필요
받은 지 **4시간이 지났는데 아직 회신/전달하지 않은** 메일이 모입니다. (최근 7일, 받은 편지함과 하위 폴더)

**목록에 넣지 않는 메일** (메일 폭탄 속에서 진짜 답할 것만 남기기 위해)
- 내가 **참조(CC)** 로만 받은 메일, 단체 주소로 받은 메일 → `TODO_ONLY_TO_ME`
- 받는 사람이 **10명 넘는** 단체 메일 → `TODO_MAX_RECIPIENTS`
  - 단, 위 두 경우도 **본문에서 내 이름을 불렀으면 포함**합니다 (🟣 내 앞으로 온 메일)
- 뉴스레터·시스템 알림 (no-reply 주소, 수신거부 링크가 있는 메일)
- 부재중 자동회신, 회의 초대
- 이미 **회신 / 전체 회신 / 전달** 한 메일
- 같은 스레드에 내가 나중에 메일을 보낸 경우 (휴대폰에서 답한 경우 포함)
- 플래그를 **완료**로 표시한 메일, `MarkDone` 한 메일

**리마인드**: 매일 **9시, 14시**에 "내 답장 필요 N건 (안 읽음 M건)" 알림 → 클릭하면 목록이 열립니다.
목록 위쪽 **[읽지 않음]** 필터를 누르면 아직 확인도 안 한 메일만 볼 수 있습니다.

### 🟠 답장 대기
- 최근 30일 동안 보낸 메일 중 **보낸 지 3일이 지났는데** 그 스레드에 **다른 사람의 메일이 하나도 오지 않은** 메일이 모입니다.
- 같은 스레드에 내가 독촉 메일을 다시 보냈다면 **가장 마지막 메일 하나만** 남습니다.
- 상대가 답하면 즉시, 동료가 대신 답한 경우는 다음 검사 때 빠집니다.
- 목록에서 메일을 열어 **전달 / 다시 보내기**로 바로 독촉하면 편합니다.

### ✅ 완료 처리 (`MarkDone`)
메일을 선택(여러 개 가능)하고 실행하면:
- 모든 목록에서 **빠지고**
- **다시는 목록에 들어오지 않습니다.** (메일 안에 숨은 표시를 저장)

Outlook 기본 기능인 **플래그 > 완료로 표시** 를 해도 `내 답장 필요` 에서 빠집니다.

## 알림이 뜨는 시점

| 언제 | 알림 |
|---|---|
| 내 메일에 회신 도착 | "내 메일에 회신이 왔습니다" + 보낸 사람 / 제목 |
| 매일 9시, 14시 | "메일 리마인드" — 내 답장 필요 N건 / 답장 대기 N건 (버튼으로 각 목록 열기) |
| Outlook 시작 시 | 꺼져 있는 동안 온 회신 요약, 그 시각에 해당하는 리마인드 |

> 리마인드 시각 확인은 **새 메일이 도착할 때** 합니다. 메일이 많은 환경에서는 거의 정시에 뜨지만,
> 메일이 한동안 안 오면 그다음 메일이 올 때 뜹니다.
> 목록 내용도 새 메일이 올 때 1시간마다 갱신됩니다. 바로 갱신하려면 `CheckMyTodo` / `CheckNoReply`.

## 설정 바꾸기

`ReplyAlert` 모듈 맨 위 **설정** 부분의 값을 바꾸고 저장하면 됩니다.

**내 메일 회신**

| 설정 | 기본값 | 설명 |
|---|---|---|
| `MATCH_WHOLE_THREAD` | `False` | `True` 면 내 메일이 포함된 스레드의 모든 답장 표시 (거래처 회신에 동료가 전체회신한 경우 등) |
| `CLEAR_REPLY_MARK_WHEN_I_REPLY` | `True` | 그 회신에 내가 다시 답하면 목록에서 빠짐 |
| `SCAN_DAYS` / `STARTUP_SCAN_DAYS` | `14` / `1` | 수동 검사 기간 / Outlook 시작 시 검사 기간 |

**내 앞으로 온 메일**

| 설정 | 기본값 | 설명 |
|---|---|---|
| `ATTENTION_ENABLED` | `True` | 기능 사용 |
| `ATTENTION_NAMES` | `"Jennifer;김나현;김 나현"` | 나를 부르는 이름 (세미콜론으로 구분, 대소문자 무시) |
| `ATTENTION_LINES` | `5` | 본문 앞에서 몇 줄까지 볼지 |
| `ATTENTION_TOAST` | `False` | `True` 면 도착 시 Windows 알림 |
| `CLEAR_ATTENTION_WHEN_I_REPLY` | `True` | 내가 회신하면 목록에서 빠짐 |

**내 답장 필요**

| 설정 | 기본값 | 설명 |
|---|---|---|
| `TODO_ENABLED` | `True` | 기능 사용 |
| `TODO_MIN_HOURS` | `4` | 받은 지 몇 시간 지나도 회신 안 했으면 표시 |
| `TODO_LOOKBACK_DAYS` | `7` | 최근 며칠 동안 받은 메일까지 |
| `TODO_ONLY_TO_ME` | `True` | `False` 면 참조(CC)로 받은 메일도 포함 |
| `TODO_MAX_RECIPIENTS` | `10` | 받는 사람이 이보다 많으면 제외 |
| `TODO_INCLUDE_SUBFOLDERS` | `True` | 받은 편지함 하위 폴더도 검사 |
| `TODO_REFRESH_MINUTES` | `60` | 목록 자동 갱신 간격 |

**답장 대기**

| 설정 | 기본값 | 설명 |
|---|---|---|
| `FOLLOWUP_ENABLED` | `True` | 기능 사용 |
| `FOLLOWUP_DAYS` | `3` | 보낸 지 며칠 지나도 답이 없으면 표시 |
| `FOLLOWUP_LOOKBACK_DAYS` | `30` | 최근 며칠 동안 보낸 메일까지 |
| `FOLLOWUP_SKIP_MY_REPLIES` | `False` | `True` 면 내가 보낸 답장(RE:)은 추적하지 않고 새 메일/전달만 |

**알림**

| 설정 | 기본값 | 설명 |
|---|---|---|
| `REMIND_HOURS` | `"9,14"` | 리마인드 시각. 예: `"9,13,17"`, 끄려면 `""` |
| `SHOW_TOAST` | `True` | Windows 알림 |
| `SHOW_POPUP` | `False` | 회신 도착 시 메시지 박스 (확인을 눌러야 닫힘) |
| `CLICK_TO_OPEN` | `True` | 알림 클릭 시 메일/목록 열기 |
| `CREATE_LISTS` | `True` | 목록 폴더 자동 생성 + 즐겨찾기 추가 |
| `EXTRA_MY_ADDRESSES` | `""` | 내 별칭 주소 (예: `"sales@company.com;me@company.com"`) |

범주/목록 이름은 `CATEGORY_NAME`, `TODO_CATEGORY`, `FOLLOWUP_CATEGORY` 등에서 바꿀 수 있습니다.

## 어떻게 판단하나요?

- **내 메일 회신**: 받은 메일 안의 "어떤 메일에 대한 답장인지" 정보(In-Reply-To)를 **보낸 편지함**의 메일과 비교합니다. 없으면 같은 대화(스레드)에서 찾습니다. 제목의 "RE:" 로 판단하지 않기 때문에 남의 메일에 대한 RE: 는 표시되지 않습니다.
- **내 답장 필요**: Outlook 이 메일마다 기록하는 "마지막 작업(회신/전달)" 정보와, 같은 스레드에 내가 나중에 보낸 메일이 있는지를 봅니다.
- **답장 대기**: 내가 보낸 메일 이후 같은 스레드에 다른 사람 메일이 왔는지를 봅니다.

## 문제 해결

**목록에 쓸데없는 메일이 너무 많아요**
- 그 메일을 선택하고 `MarkDone` (여러 개 한꺼번에 가능)
- `내 답장 필요`: `TODO_MIN_HOURS` 를 24 로 늘리거나 `TODO_MAX_RECIPIENTS` 를 5 정도로 줄이세요.
- `답장 대기`: "감사합니다" 같은 마무리 답장이 많이 잡히면 `FOLLOWUP_SKIP_MY_REPLIES = True`

**"내 앞으로 온 메일" 이 안 잡혀요 / 엉뚱한 메일이 잡혀요**
- 메일을 선택하고 `TestSelectedMail` → "내 앞으로 온 메일: 맞음 [찾은 줄]" 로 어느 줄 때문인지 나옵니다.
- 잡히지 않는 호칭이 있으면 `ATTENTION_NAMES` 에 추가하세요. (예: `Jenny`, `Ms. Kim`, `김 차장`)
- 인사말이 본문 6번째 줄 이후에 있으면 `ATTENTION_LINES` 를 늘리세요.

**들어가야 할 메일이 안 들어가요 / 빠져야 할 메일이 남아 있어요**
- 메일을 선택하고 `TestSelectedMail` 을 실행하면 판단 근거가 나옵니다.
  - "받는 사람(To)에 내가 없음" → 참조로 받았거나 단체 주소로 받은 메일. 포함하려면 `TODO_ONLY_TO_ME = False`
  - "내가 보낸 메일인가" 판단이 틀리면 → `EXTRA_MY_ADDRESSES` 에 내 다른 주소 추가
- 상대가 답장이 아닌 **새 메일**로 답한 경우는 연결을 알 수 없습니다. `MarkDone` 으로 정리하세요.

**알림이 안 떠요**
- `TestToast` 를 실행해 보세요. 안 뜨면 Windows **설정 > 시스템 > 알림** 에서 알림이 켜져 있는지, "방해 금지 / 집중 모드" 가 꺼져 있는지 확인하세요.
- 회사 정책으로 PowerShell 이 막혀 있으면 Windows 알림이 동작하지 않습니다. 회신 알림은 `SHOW_POPUP = True` 로 메시지 박스로 받을 수 있습니다. (목록과 색 표시는 상관없이 동작합니다)

**알림을 클릭해도 메일이 안 열려요**
- 클릭 처리는 `%APPDATA%\ReplyAlert\open.vbs` 스크립트가 합니다(Outlook 시작 시 자동 생성). 회사 정책으로 **Windows Script Host(wscript)** 가 막혀 있으면 열리지 않습니다.
- 메일이 열렸는데 화면 뒤에 숨어 있으면 작업 표시줄의 Outlook 을 눌러 주세요.
- 처음 클릭할 때 "이 앱을 여시겠습니까?" 같은 확인 창이 뜨면 허용해 주세요.

**목록 폴더가 안 보이거나 비어 있어요**
- Outlook 을 재시작하거나 `ShowMyTodoList` 등을 실행하세요.
- **폴더 목록 > 검색 폴더** 아래에 있으면 끌어서 즐겨찾기에 놓으면 됩니다.
- 계속 비어 있으면 직접 만들 수 있습니다: **검색 폴더 우클릭 > 새 검색 폴더 > "범주별로 분류된 메일"** → 해당 범주 선택.
  (`답장 대기` 는 **사용자 지정 검색 폴더 만들기** → 폴더: 보낸 편지함 → 조건 > 기타 선택 항목 > 범주: `답장 대기`)

**Outlook 이 시작할 때나 하루 첫 메일 때 잠깐 느려요**
- 목록을 처음 만들 때 최근 메일을 한 번에 검사하기 때문입니다. 메일이 아주 많다면 `TODO_LOOKBACK_DAYS`, `FOLLOWUP_LOOKBACK_DAYS` 를 줄이세요.

**매크로가 실행이 안 돼요 / 재시작하면 안 돼요**
- 매크로 설정이 "모든 매크로 사용 안 함" 이면 동작하지 않습니다.
- 매번 "매크로 사용" 을 누르기 귀찮다면 자체 서명을 하세요:
  1. 시작 메뉴에서 **"VBA 프로젝트용 디지털 인증서"** (SelfCert.exe) 실행 → 이름 입력해 인증서 생성
  2. VBA 편집기 **도구 > 디지털 서명 > 선택** → 만든 인증서 선택 → 저장 후 재시작
  3. 처음 뜨는 경고에서 **"이 게시자의 모든 문서 신뢰"** 클릭

**한글이 깨져 보여요 (VBA 편집기에서)**
- `ReplyAlert.bas` 는 한글 Windows 인코딩(CP949)으로 저장되어 있습니다. Windows 의 "유니코드를 지원하지 않는 프로그램용 언어" 가 한국어가 아니면 깨질 수 있습니다. 이 경우 범주/목록 이름 설정을 원하는 이름으로 직접 바꿔 주세요.

## 제거
1. VBA 편집기에서 `ReplyAlert` 모듈 우클릭 > **제거**, `ThisOutlookSession` 에 붙여넣은 코드 삭제 → 저장 → 재시작
2. 범주 `내 메일 회신`, `내 앞으로 온 메일`, `내 답장 필요`, `답장 대기` 는 **홈 > 분류 > 모든 범주** 에서 삭제
3. 검색 폴더 `내 메일 회신`, `내 앞으로 온 메일`, `내 답장 필요`, `답장 대기` 는 우클릭 > **폴더 삭제** (메일은 지워지지 않습니다)
4. 클릭 처리기: `%APPDATA%\ReplyAlert` 폴더 삭제, 레지스트리 `HKEY_CURRENT_USER\Software\Classes\replyalert` 키 삭제
5. 설정 기록: 레지스트리 `HKEY_CURRENT_USER\Software\VB and VBA Program Settings\ReplyAlert` 키 삭제
